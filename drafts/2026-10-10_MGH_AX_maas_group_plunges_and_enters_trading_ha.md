It hasn’t.

### The Mental Model: Sorosian Reflexivity in Reverse

George Soros famously outlined how markets operate on **Reflexivity**: prevailing biases shape the fundamentals, which in turn validate the bias in a self-reinforcing loop.

During the run-up to $7.09, reflexivity worked to the upside:
> *Firmus plans a giant IPO -> Maas gets contracts -> Maas is re-rated as an AI infrastructure player -> Maas stock rises -> Higher stock gives Maas currency to build more datacentres.*

Now, the herd is running the reflexive loop backward:
> *Firmus shelves IPO -> AI datacentres delayed -> Maas is broken -> Dump the stock.*

```
      [ THE REFLEXIVE TRAP ]
   
       Bullish Loop (Jan-Aug 2026)
       ┌────────────────────────────────────────┐
       ▼                                        │
     Firmus IPO Buzz ──► Multiple Expands ──► Stock at $7.09
                                                │
       Bearish Reversal (Oct 2026)             │
       ┌────────────────────────────────────────┘
       ▼
     IPO Shelved ──► Wholesale Dump ──► Stock at $4.63 (Oversold)
       │
       ▼
     [ REALITY CHECK ]: Does crushing rock require a $44B IPO?
     No. The core asset base remains unaffected.
```

The error in reflexive loops occurs when the market assumes the underlying asset is entirely dependent on the financial narrative. 

If Firmus were a software company with no revenue, shelving its IPO might be a death sentence. But Maas Group is not software. It is excavators, diesel, basalt, crushed gravel, and road bases. 

Does the postponement of an AI IPO eliminate the state of New South Wales’ demand for aggregate to build bypasses, hospital precincts, and rail lines? No. 

By penalizing Maas Group as if it were a direct equity vehicle of Firmus, the market has handed fundamental value investors a massive **Margin of Safety**. You are acquiring regional monopoly-like quarry assets at near cyclical-trough multiples, receiving the AI upside essentially for zero.

### Quantitative Blueprint: The Asymmetric Dislocation Scanner

To identify anomalies like this programmatically, run the following Python script. It queries asset price action, measures statistical stretch below historical bands, verifies whether volume capitulation has taken place, and flags setups where technical despair diverges from fundamental support.

You can paste this script directly into a **Google Colab** notebook:

```python
"""
MGH Anomaly Scanner: Post-Capitulation Dislocation Engine
Author: Rowan (Quantitative Investment Analyst)
Environment: Python 3.10+ / Google Colab
"""

import yfinance as yf
import pandas as pd
import numpy as np

def analyze_dislocation(ticker: str, lookback_days: int = 252):
    print(f"[*] Fetching historical market data for {ticker}...")
    df = yf.download(ticker, period="1y", interval="1d", progress=False)
    
    if df.empty or len(df) < 50:
        raise ValueError(f"Insufficient historical data for {ticker}")

    # Flatten multi-index columns if present (yfinance modern update)
    if isinstance(df.columns, pd.MultiIndex):
        df.columns = df.columns.get_level_values(0)

    close = df['Close']
    volume = df['Volume']

    # 1. 14-Day Relative Strength Index (RSI)
    delta = close.diff()
    gain = (delta.where(delta > 0, 0)).rolling(window=14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window=14).mean()
    rs = gain / (loss + 1e-9)
    df['RSI'] = 100 - (100 / (1 + rs))

    # 2. Bollinger Bands & %B Calculation
    df['SMA_20'] = close.rolling(window=20).mean()
    df['STD_20'] = close.rolling(window=20).std()
    df['Upper_BB'] = df['SMA_20'] + (2 * df['STD_20'])
    df['Lower_BB'] = df['SMA_20'] - (2 * df['STD_20'])
    
    # %B = (Price - Lower) / (Upper - Lower)
    df['Percent_B'] = (close - df['Lower_BB']) / (df['Upper_BB'] - df['Lower_BB'])

    # 3. Volume Capitulation Ratio (5d vs 30d Average)
    df['Vol_5d'] = volume.rolling(window=5).mean()
    df['Vol_30d'] = volume.rolling(window=30).mean()
    df['Capitulation_Ratio'] = df['Vol_5d'] / df['Vol_30d']

    # 4. Drawdown from 52-week High
    rolling_max = close.rolling(window=lookback_days, min_periods=1).max()
    df['Drawdown'] = (close - rolling_max) / rolling_max

    latest = df.iloc[-1]
    
    # Quantitative Filter Thresholds
    is_oversold = latest['RSI'] < 30.0
    is_outside_bands = latest['Percent_B'] < 0.0
    is_volume_spike = latest['Capitulation_Ratio'] > 1.8
    is_deep_drawdown = latest['Drawdown'] < -0.25

    print("\n" + "="*50)
    print(f"ANOMALY AUDIT: {ticker}")
    print("="*50)
    print(f"Last Close Price          : ${latest['Close']:.2f}")
    print(f"14-Day RSI                : {latest['RSI']:.2f}  (Trigger: <30)")
    print(f"Bollinger %B              : {latest['Percent_B']:.2f} (Trigger: <0.0)")
    print(f"Volume Capitulation Ratio : {latest['Capitulation_Ratio']:.2f}x (Trigger: >1.8x)")
    print(f"Drawdown from High        : {latest['Drawdown']*100:.1f}%")
    print("="*50)

    # Opportunity Scoring Engine (0 to 10)
    score = 0
    if is_oversold: score += 3.0
    if is_outside_bands: score += 2.5
    if is_volume_spike: score += 2.5
    if is_deep_drawdown: score += 2.0

    print(f"OPPORTUNITY SCORE: {score:.1f} / 10.0")
    if score >= 7.0:
        print("[VERDICT]: ASYMMETRIC BOUNCE SETUP IDENTIFIED.")
    else:
        print("[VERDICT]: CRITERIA NOT FULLY MET. PASS.")
    print("="*50)

    return df

# Run the engine
if __name__ == "__main__":
    # In live environments, MGH.AX on Yahoo Finance covers Maas Group Holdings
    try:
        data = analyze_dislocation("MGH.AX")
    except Exception as e:
        print(f"Execution Note: Run during market open/post-halt. Error details: {e}")
```
